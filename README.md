1. Необходимое ПО:
- Delphi 13 — для сборки проекта при необходимости.
- IIS с поддержкой ISAPI Extensions.
- Microsoft SQL Server Express.
- SQL Server Management Studio (SSMS) — для управления базой данных.

2. Настройка базы данных:
- Запустить SQL Server Express.
- Создать базу данных TaskManager из предоставленного SQL-скрипта.
- Проверить строку подключения в проекте. Текущая конфигурация использует экземпляр localhost\SQLEXPRESS и Windows Authentication.
- Предоставить Windows-учётной записи, от имени которой приложение подключается к SQL Server, необходимые права на чтение и изменение данных.

3. Подготовка файлов приложения
- Создать каталог для опубликованных файлов приложения
В каталоге должны находится:
- Project1.dll (скомпилированное приложение для Win64, конфигурация Release)
- css — каталог со всеми необходимыми CSS-файлами.

4. Настройка IIS
- Открыть диспетчер IIS командой inetmgr.
- Создать новый сайт
- В качестве физического пути указать каталог, в котором расположены Project1.dll и папка css.
- Настроить привязку HTTP с использованием свободного порта.
- Назначить пул приложений со следующими параметрами:
  1. Версия среды - без управляемого кода
  2. Режим управляемого конвейера: встроенный
  3. Enable 32-Bit Applications: False.
- В разделе ISAPI and CGI Restrictions разрешить выполнение Project1.dll
- Проверить наличие обработчика IsapiModule для ISAPI DLL и права чтения и выполнения для каталога приложения

5. Запуск и проверка
Открыть в браузере: http://localhost:ВАШ_ПОРТ/Project1.dll/login
Проверить следующие функции:
- Регистрация пользователя
- Авторизация пользователя
- Открытие главной страницы после авторизации
- Создание, редактирование и удаление задачи
- Выход из учётной записи

6. Возможные проблемы с подключением к БД
Если приложение не подключается к базе данных, необходимо проверить имеет ли Windows-учётная запись приложения IIS необходимые права в SQL Server.
